## Таблица №1 (документ / продукция / сумма) — только приложение

**В ячейки таблицы переменные не вставляйте** — CRM заполняет таблицу после рендера.

В шаблоне оставьте:

1. Строку заголовков (как сейчас): «Наименование документа» | «Продукция» | «Стоимость…»
2. **Вторую строку пустой** (образец для клонирования) — минимум одна строка обязательна

При скачивании строки добавляются по числу позиций в CRM.

## Реквизиты и форматирование (Word и Excel)

Чтобы сохранить **ширину колонок, высоту строк, шрифт, границы и переносы**, используйте
только плейсхолдеры `{{ ... }}` прямо в шаблоне. CRM подставляет значения **без перезаписи
форматирования ячейки** — меняется только содержимое.

### Word (docx)

CRM больше не перезаписывает ячейки реквизитов программно.

Примеры переменных для реквизитов:

- `{{ executor_short_name }}`
- `{{ customer_short_name }}`
- `{{ legal_address }}`
- `{{ customer_inn_kpp }}`
- `{{ ogrn }}`
- `{{ settlement_account }}`
- `{{ bank_name }}`
- `{{ bik }}`
- `{{ correspondent_account }}`
- `{{ director_name_genitive }}`
- `{{ signer_position }}`
- `{{ signer_basis }}`

## Сумма прописью (п. 4, п. 5)

| Переменная | Пример |
|------------|--------|
| `{{ total_amount_full }}` | `125 000 руб. 00 коп. (сто двадцать пять тысяч рублей 00 копеек)` |
| `{{ total_amount_kopecks }}` | только цифрами с копейками |
| `{{ total_amount_words }}` | только прописью |
| `{{ advance_amount_full }}` | аванс, цифры + прописью |
| `{{ balance_amount_full }}` | остаток, цифры + прописью |

## Пункт 5 — условная оплата

В Word (Jinja2 / docxtpl):

```
{% if is_full_payment %}
Ваш текст для 100% оплаты. Сумма: {{ total_amount_full }}.
{% else %}
{{ payment_clause_5_partial }}
{% endif %}
```

`payment_clause_5_partial` — готовый абзац для частичной оплаты (проценты и суммы подставляются из CRM).

`is_full_payment` — true, если аванс 100%.

## Акт выполненных работ (XLSX)

Шаблон `act_template.xlsx`. В ячейках — плейсхолдеры (форматирование задаётся в Excel):

| Плейсхолдер | Содержимое |
|-------------|------------|
| `{{ act_header }}` | Заголовок «АКТ №… от …» |
| `{{ act_preamble }}` | Преамбула с подписантами |
| `{{ line_text }}` | Наименование работ в таблице |
| `{{ line_unit }}` | «шт» |
| `{{ line_qty }}` | 1 |
| `{{ line_price }}` | Цена (число) |
| `{{ line_sum }}` | Сумма строки (число) |
| `{{ total_sum }}` | Итого (число) |
| `{{ amount_words }}` | Сумма прописью |
| `{{ done_text }}` | Текст о выполнении работ |
| `{{ executor_block }}` | Реквизиты исполнителя |
| `{{ customer_block }}` | Реквизиты заказчика |
| `{{ sign_executor_label }}` / `{{ sign_executor_name }}` | «Сдал» / ФИО |
| `{{ sign_customer_label }}` / `{{ sign_customer_name }}` | «Принял» / ФИО |

Можно использовать и отдельные части: `{{ act_number }}`, `{{ act_date }}`, `{{ executor_sign }}`, `{{ customer_rep }}`.

Если в шаблоне **нет** `{{ }}`, CRM заполнит ячейки по старым координатам (форматирование может частично сбиться).

## Счета (XLS)

Шаблон `invoice_template.xls` — по образцу из NSK. В ячейках — плейсхолдеры:

| Плейсхолдер | Содержимое |
|-------------|------------|
| `{{ invoice_date_header }}` | «Счет № от …» |
| `{{ buyer_name }}` | Покупатель |
| `{{ buyer_address }}` | Адрес |
| `{{ buyer_inn_kpp }}` | ИНН / КПП |
| `{{ line_text }}` | Наименование услуги |
| `{{ line_qty }}` | Количество |
| `{{ line_price }}` | Цена |
| `{{ line_sum }}` | Сумма |
| `{{ line_vat }}` | НДС («0,00») |
| `{{ line_total }}` | Всего по строке |
| `{{ total_label }}` | «Итого:» |
| `{{ total_qty }}` | «1.0» |
| `{{ total_price_dash }}` | «-» |
| `{{ total_sum }}` / `{{ total_amount }}` | Итоговая сумма |
| `{{ total_items_text }}` | «Всего наименований…» |
| `{{ amount_words }}` | Сумма прописью |

Если в шаблоне **нет** `{{ }}`, CRM заполнит ячейки по старым координатам (форматирование может частично сбиться).

Порядок счетов:
- аванс &lt; 100%: сначала счёт **ADVANCE**, потом **BALANCE**
- аванс 100%: один счёт **FULL**

Вкладка **Счета** в CRM или блок «Счета» в карточке приложения.
